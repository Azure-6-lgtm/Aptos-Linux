Linux, made simple.

Aptos-Linux is a minimal, Arch-based distribution that aims to be easy for beginners, with a clean, macOS-inspired desktop.

Download Learn more
Heads up: Aptos-Linux is still in early development. Things will change, break and improve. It is not ready for daily use yet.

What is Aptos-Linux?

We're a small group of friends building a distribution we'd want to hand to someone trying Linux for the first time.

Built on Arch

Aptos-Linux is based on Arch Linux, giving it a solid and well-known foundation to build on.

Minimal by design

A small base system with no pile of preinstalled extras. You add what you need.

Beginner friendly

We want setup and everyday use to feel approachable, without needing to read a wiki first.

Clean interface

A tidy, macOS-inspired look that stays out of your way.

Open source

Developed in the open. Read the code, report problems and help shape it.

Work in progress

Features and details are still being decided, and feedback now makes a real difference.
